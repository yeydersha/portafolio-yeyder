## 2. Corrección de GlassCard

### Problema identificado
El componente GlassCard tenía **duplicación de estilos**:
- `style={{ backdropFilter: `blur(${blur}px)` }}` (estilo inline)
- `className` con `blur-[var(--glass-blur)]` y `-webkit-backdrop-filter: blur-[var(--glass-blur)]` (clase CSS)

Esto provocaba que el efecto glassmorphism no se mostrara de forma consistente, ya que ambos estilos competían en el navegador.

### Solución implementada
Aplicar **única estrategia coherente**: usar exclusivamente `backdrop-blur-[var(--glass-blur)]` en las clases CSS, eliminando los estilos inline duplicados.

### Archivo modificado: `src/components/ui/glass-card.tsx`
- Removido `blur = 20` del destructuring de props
- Removido `style` inline con `backdropFilter` y `WebkitBackdropFilter`
- Sustituido `blur-[var(--glass-blur)]` por `backdrop-blur-[var(--glass-blur)]`
- Mantenidas las variables CSS `--glass-blur`, `--glass-bg`, `--glass-border` en `globals.css`
- El contenido de la card sigue legible gracias al fondo translúcido y border sutil

### Variables CSS (ya definidas en `src/app/globals.css`)
```css
--glass-blur: 20px;
--glass-bg: rgba(255, 255, 255, 0.03);
--glass-border: rgba(255, 255, 255, 0.05);
```
