# Portfolio Personal - Yeyder Otero

## Visión General

Este es un portafolio web personal diseñado para mostrar la trayectoria profesional, proyectos y habilidades de **Yeyder Otero**, estudiante y desarrollador en formación. El sitio servirá como herramienta principal para la búsqueda de empleo y evolucionará conforme el propietario adquiere más experiencia profesional.

## Objetivos

- Presentar información personal y perfil profesional de manera clara y organizada.
- Mostrar proyectos académicos, personales y aplicaciones desarrolladas.
- Detallar tecnologías y habilidades con niveles de dominio reales.
- Exhibir formación académica y certificaciones obtenidas.
- Compartir experiencia laboral presente y futura.
- Ofrecer una hoja de vida descargable en formato PDF.
- Proporcionar enlaces profesionales y medios de contacto directos.

## Tecnologías

- **Next.js 16** con App Router
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Motion for React**
- **Lucide React**
- **ESLint**
- **Turbopack**
- **Git**
- **Vercel** (para despliegues futuros)

## Filosofía de Diseño

- Estilo editorial minimalista
- Tema oscuro como identidad principal
- Glassmorphism elegante y moderado
- Tipografía moderna con excelente jerarquía visual
- Animaciones fluidas, modernas y equilibradas
- Diseño responsive, accesible y de alto rendimiento
