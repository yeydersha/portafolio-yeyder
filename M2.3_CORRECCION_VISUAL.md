# M2.3 — Corrección visual de componentes y sistema de diseño

## 1. Diagnóstico de problemas visuales

Se identificaron los siguientes problemas en la página de demostración M2:

1. **Variables CSS faltantes** — El componente GlassCard usaba `var(--glass-blur)`, `var(--glass-bg)`, `var(--glass-border)` pero estas no estaban definidas en ningún archivo.

2. **Conflicto de estilos en GlassCard** — El componente tenía tanto `style={{ backdropFilter: blur(${blur}px) }}` como clases CSS `blur-[var(--glass-blur)]`. Estos se anulan mutuamente, provocando que el efecto glassmorphism no funcionara correctamente.

3. **TechTags con espaciado muy reducido** — `h-6 px-3 text-xs comprimía el contenido demasiado`, haciendo que las etiquetas se tocaran.

4. **Botones con apariencia predeterminada** — La página usaba `className` inline con clases Tailwind en lugar del componente `Button` reutilizable M2.

5. **GlassCards en page.tsx eran divs hand-crafted** — En lugar de usar el componente `GlassCard`, la página tenía divs con estilos duplicados y inconsistentes.

6. **TechTags en page.tsx eran spans hand-crafted** — Igual que los glasscards, usando estilos inline en lugar del componente `TechTag`.

7. **Errores TypeScript** — Uso de `class` en lugar de `className` en varios divs, y `SectionHeader` recibiendo `children` no definido en su tipo.

## 2. Correcciones implementadas

### Archivo: `src/app/globals.css`
- Se agregaron las variables CSS faltantes para glassmorphism:
  ```css
  --glass-blur: 20px;
  --glass-bg: rgba(255, 255, 255, 0.03);
  --glass-border: rgba(255, 255, 255, 0.05);
  ```

### Archivo: `src/components/ui/glass-card.tsx`
- Se eliminó el conflicto entre `style` y clases CSS
- El componente ahora usa `backdropFilter: blur(${blur}px)` en el estilo inline
- Las clases CSS usan `blur-[var(--glass-blur)]` para consistencia con el diseño system
- Las props `background` y `borderColor` son opcionales y se aplican condicionalmente

### Archivo: `src/components/ui/tech-tag.tsx`
- Height incrementado: `h-6` → `h-7`
- Padding incrementado: `px-3` → `px-3.5`
- Mejor legibilidad y respiro visual en el grid

### Archivo: `src/app/page.tsx`
- **Botones**: Reemplazados `className` inline por `<Button variant="primary">` etc.
- **GlassCards**: Reemplazados divs hand-crafted por `<GlassCard>` componente
- **TechTags**: Reemplazados spans hand-crafted por `<TechTag>` componente
- **SectionHeader**: Quitado `children` `<p>`, el texto ahora está fuera del componente (SectionHeader ya renderiza el subtitle como párrafo)
- **Imports**: Removido `import Image from "next/image"` (nunca usado)
