# M2.1 — Reparación Urgente de Tailwind CSS

## Causa Raíz

El archivo `src/app/globals.css` tenía las directivas `@tailwind` comentadas con sintaxis de bloque `/* */`:

```css
/* Antes (incorrecto):
/* @tailwind base; */
/* @tailwind components; */
/* @tailwind utilities; */
```

Esto impedía que Tailwind CSS v4 generara los estilos utility, dejando la página sin diseño visual a pesar de que el build de TypeScript pasaba correctamente.

## Solución

Se quitaron los marcadores `/* */` de las tres directivas `@tailwind`, convirtiéndolas en at-rules activas:

```css
/* Después (correcto):
@tailwind base;
@tailwind components;
@tailwind utilities; */
```

- `src/app/globals.css` - Activación de directivas `@tailwind`
